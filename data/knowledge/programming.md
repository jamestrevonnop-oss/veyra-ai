# Programming

Programming is the process of creating instructions that computers can execute.

JavaScript is a programming language commonly used for web applications and can also run on servers through environments such as Node.js.

Python is a general-purpose programming language widely used for automation, scientific computing, data analysis, machine learning, and web development.

HTML describes the structure of web pages. CSS controls presentation and layout. JavaScript can provide behavior and interactivity.

An API, or application programming interface, is a defined way for software systems to communicate with each other.

A REST API commonly exposes resources through HTTP methods such as GET, POST, PUT, PATCH, and DELETE.
